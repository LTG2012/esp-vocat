# Magnetic Slide Switch UI Demo

[中文版本](./README_CN.md)

This example demonstrates how to receive magnetic event messages from the EchoEar base via UART and drive LVGL UI animations in response on the display.

- [JLC esp-vocat Open Source Hardware Link](https://oshwhub.com/esp-college/echoear)
- [JLC Rotating Base Open Source Hardware Link](https://oshwhub.com/esp-college/esp-echoear-base)
- [Supporting Rotating Base Gitee Repository](https://gitee.com/esp-friends/esp-vocat-base)

## Features

- Receives magnetic event frames from the rotating base via UART
- Parses a custom serial frame protocol (header `AA 55`, with checksum)
- Triggers different LVGL UI animations (bell, fish, ice cream, donut, phone, etc.) based on event type
- Briefly displays the event name on screen when an event occurs (auto-fades after 800ms)

## Hardware Required

- **Board:** esp-vocat
- **Display:** 3.5-inch LCD screen
- **Rotating Base:** Communicates with the main board via UART
  - RX (board receives): GPIO4
  - TX (board transmits): GPIO5
  - Baud rate: 115200

## Serial Frame Protocol

```
Frame format: [AA][55][LEN_H][LEN_L][CMD][DATA...][CHECKSUM]

Fields:
  AA 55       - Frame header (fixed 2 bytes)
  LEN_H/LEN_L - Data section length (big-endian, includes CMD byte)
  CMD         - Command code (magnetic event: 0x03)
  DATA        - Data bytes (magnetic event: 2-byte event code, big-endian)
  CHECKSUM    - Sum of all bytes from CMD to end of DATA (8-bit truncated)
```

**Example frame (slide down event, code 0x0001):**

```
AA 55 00 03 03 00 01 04
```

## Supported Magnetic Events

| Code | Event Name | UI Animation |
|------|-----------|--------------|
| 0 | INIT | Power-on initial state, no animation |
| 1 | SLIDE_DOWN | Bell image slides from top-left to bottom-right (200ms) |
| 2 | SLIDE_UP | Bell image slides from bottom-right to top-left (200ms) |
| 3 | REMOVE_FROM_UP | Bell flies off screen from top-left to upper-right (200ms) |
| 4 | REMOVE_FROM_DOWN | Bell flies off screen from bottom-right to the right (200ms) |
| 5 | PLACE_FROM_UP | Bell flies in from upper-right to top-left (200ms) |
| 6 | PLACE_FROM_DOWN | Bell flies in from the right to bottom-right (200ms) |
| 7 | SINGLE_CLICK | Bell swings and rotates 45°, then returns (300ms) |
| 8 | FISH_ATTACHED | Fish accessory image fade-in animation |
| 9 | FISH_DETACHED | Fish accessory image fade-out animation |
| 10 | PAIRING | EchoEar base slides out + pairing icon appears (500ms delay) |
| 11 | PAIRING_CANCELLED | Pairing icon disappears + EchoEar base returns |
| 12 | ICE_CREAM_ATTACHED | Ice cream accessory image appears with entry animation |
| 13 | ICE_CREAM_DETACHED | Ice cream accessory image plays exit animation |
| 14 | DONUT_ATTACHED | Donut accessory image appears with entry animation |
| 15 | DONUT_DETACHED | Donut accessory image plays exit animation |
| 16 | IPHONE_LEAN_FRONT | iPhone leans against front of base animation (Z-axis increase) |
| 17 | IPHONE_LEAN_FRONT_DETACHED | iPhone moves away from front of base animation |
| 18 | IPHONE_UNDER_BASE | iPhone pushed under base animation (Z-axis negative) |
| 19 | IPHONE_UNDER_BASE_DETACHED | iPhone moves away from under base animation |

## Build and Flash

**Prerequisite:** ESP-IDF `release/v5.3` or later.

```bash
cd examples/mag_slide_switch
idf.py -p PORT flash monitor
```

Press `Ctrl-]` to exit the serial monitor.
